# Better Rhodes Modern Agentic Rebuild

Modern responsive rebuild of [betterrhodes.co](https://www.betterrhodes.co/) with agentic features for customers and vendors.

## Key Features
- **Agentic Hero**: AI chat agent for product discovery and recommendations.
- **Brands Portfolio**: Interactive cards for Wander & Found, Splash Of, Seir Hill, Sir James 101.
- **White-Label Product Maker**: Configurator for labels + integration point for video maker (AutoVidTurbo).
- **Staff Portal**: Links to **metaverve-work** as the backend platform for staff to plan, manage boards/tasks, and interact.
- **Marketing Elements**: Pulls concepts from marketingdepartment repo.
- **Learning Mechanics**: Brain/journal integration inspired by CROSDOGGY-4000 for continuous improvement and insights.
- Fully responsive, Tailwind-powered, premium aesthetic.

## Integrations
- **Backend**: metaverve-work (Next.js work management with auth, Kanban, tasks) — staff login.
- **Video**: AutoVidTurbo for social video generation (captions, TTS, compose).
- **Marketing**: marketingdepartment for campaign/audience elements.
- **Learning**: CROSDOGGY-4000 brain/journal for agent learning loops.
- API-ready for product maker, label generation (e.g. Canva), and platform-side extensions.

## Deploy
Static site — deploy to Vercel, Netlify, or GitHub Pages. For full platform, integrate with metaverve-work via auth and API routes.
