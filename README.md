# Better Rhodes Modern Platform

Professional agentic rebuild of Better Rhodes.

## Features
- Matches original aesthetic (beige, serif, orange accents, circular product treatment)
- Rhodey AI agent for discovery and white-label guidance
- White-label product maker (brand, label, social video)
- Staff portal integration points for **metaverve-work** (Better Auth + Postgres + Kanban)
- AutoVidTurbo for social video generation
- Learning journal patterns from CROSDOGGY-4000

## Staff Backend
Clone and deploy `metaverve-work` separately. Point staff links and API jobs to the live instance.

## Video
AutoVidTurbo worker endpoints handle social video composition from white-label briefs.

Open `index.html` for the public site prototype.
